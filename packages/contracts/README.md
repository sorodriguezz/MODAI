# @modai/contracts

Workspace interno privado. Se incorpora al CLI durante la compilación y no se publica por separado en npm.

Tipos y esquemas de paquetes, agentes, capacidades y entradas de la API MODAI. Incluye validación de manifiestos, políticas de firma y destinos de instalación. No depende del servidor.

Requiere Node >=26.13.0 y <27, al igual que el resto de MODAI.
