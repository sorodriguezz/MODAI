# Project Memory

La memoria está aislada por el `projectId` del manifiesto. Usa:

```sh
modai remember "Usamos UUIDv7 como identificador público" --kind decision
modai recall "identificadores"
```

Guarda decisiones, restricciones y aprendizajes estables. No guardes secretos, credenciales, contenido efímero ni volcados extensos de conversaciones.
