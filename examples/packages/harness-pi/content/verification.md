# Verificación

## Gates base

- Instalación: `npm install`
- Tests: `npm test`
- Build: `npm run build`

Adapta estos comandos al package manager y scripts reales. Un comando inexistente no cuenta como verificación.

## Definition of Done

- Conducta observable verificada con el gate de la función.
- Tests, tipos, lint y build aplicables en estado conocido.
- Sin artefactos temporales ni cambios no explicados.
- Progreso, estado y handoff reflejan el repositorio real.
- Fallos preexistentes separados de regresiones nuevas.
