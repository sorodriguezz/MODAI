# Línea base de accesibilidad (WCAG 2.2 AA)

- Usa elementos nativos (`button`, `a`, `label`, `dialog`) antes que roles ARIA.
- Todo control es operable con teclado y su foco es visible.
- Contraste mínimo 4,5:1 para texto normal y 3:1 para texto grande y componentes.
- Las imágenes informativas tienen texto alternativo; las decorativas, `alt=""`.
- Los formularios asocian etiquetas y anuncian errores junto al campo.
- Respeta `prefers-reduced-motion`.
- Verifica con un lector de pantalla en un flujo principal además de herramientas automáticas.
