# Atributos de calidad frecuentes

- **Disponibilidad**: tolerancia a fallas, degradación controlada.
- **Rendimiento**: latencia, throughput, uso de recursos.
- **Modificabilidad**: costo de cambio, acoplamiento, cohesión.
- **Seguridad**: confidencialidad, integridad, superficie de ataque.
- **Operabilidad**: observabilidad, despliegue, recuperación.
- **Costo**: infraestructura, licencias y personas.

Ordénalos para el contexto concreto; no todos pueden maximizarse a la vez.
